FAQ

How does AMP capture conversations?
AMP runs as a Chrome extension that monitors supported AI chat pages. When you interact with ChatGPT, Claude, or other platforms, AMP automatically detects and stores the conversation data locally in your browser.
Is my data private?
Yes. All captured data is stored locally on your device. The extension does not transmit your conversations anywhere. If you use the desktop app, data is stored in a local SQLite database on your computer.
What is the desktop app for?
The desktop app provides persistent storage beyond browser memory limits. It uses SQLite to store unlimited conversation history locally. The extension can cascade data to the desktop app for long-term preservation.
Can I use AMP on other AI chat sites?
Yes. While AMP auto-detects 8 major platforms, you can enable capture on any website by clicking the extension icon.
Do I need the desktop app?
No. The extension works standalone with 5MB of hot memory storage. The desktop app is optional but recommended for users who want unlimited persistent storage.
Is this a subscription?
You choose! AMP offers both monthly subscriptions and lifetime one-time purchases. Lifetime gives you permanent access with all future updates included.
