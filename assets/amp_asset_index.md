## 🎬 VIDEO EDITING WORKFLOW

### Step 1: Create Project
1. Open your video editor (DaVinci Resolve, Premiere, Final Cut Pro)
2. Create new project: 1080p/4K, 24fps or 30fps
3. Set frame duration and timeline length to 90 seconds (room for audio)

### Step 2: Import Assets
1. Import all scene backgrounds as individual clips
2. Import script as text reference (open in separate window)
3. Import audio track (create or source 80-90 BPM ambient electronic music)

### Step 3: Build Timeline
1. Place scene1_hero_bg.png at 0s → 8s
2. Place scene2_core_promise_bg.png at 9s → 15s
3. Continue with remaining scenes per timing table above
4. Ensure seamless transitions between scenes (use 1s cross-fade)

### Step 4: Add Text Overlays
1. For each scene, add text layers with on-screen copy (see Text Reference section)
2. Set text to fade-in over 1-1.5s, hold per script, fade-out over 0.5-1s
3. Use white color (#ffffff), clean sans-serif font (Roboto, Inter, or similar)
4. Ensure minimum 48pt for headlines, 36pt for body text

### Step 5: Add Animations
1. Scene 3: Pan camera slowly across each platform (2.5s per platform)
2. Scene 4: Animate data flow between hot and cold storage
3. Scene 5: Animate counters from 0 to final numbers (8s each counter)
4. Scene 6: Cards appear staggered (2.5s between each)
5. Scene 7: Connection lines animate in, nodes pulse; zoom out to reveal full system

### Step 6: Add Audio
1. Import or create ambient electronic track (80-90 BPM, ~70s duration)
2. Layer with subtle tech tones aligned to text/element reveals
3. Mix levels: ambient pad -18dB, tech tones -12dB, music -6dB
4. Fade out music over final 3 seconds

### Step 7: Export
1. Export as H.264 (MP4) for web, or ProRes for archival
2. Resolution: 1920x1080 minimum (3840x2160 for 4K)
3. Frame rate: 24fps (cinematic) or 30fps (standard)
4. Audio: Stereo, 48kHz, 24-bit
5. Target file size: 200-500MB

## ✅ QUALITY CHECKLIST

Before finalizing your video:

- [ ] All text is spelled correctly (use checklist in script)
- [ ] Text dwell time is minimum 4 seconds for readability
- [ ] All transitions are smooth (1-1.5s cross-fades)
- [ ] Camera movements are slow and deliberate (no jarring pans)
- [ ] Color palette is consistent (navy + cyan + rainbow accents)
- [ ] Audio levels are balanced (no sudden jumps)
- [ ] Music matches pacing (80-90 BPM, not rushed)
- [ ] Final video is 80-85 seconds total
- [ ] Resolution is 1080p minimum (4K preferred)
- [ ] File exports without errors
